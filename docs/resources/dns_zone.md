# masterdaweb_dns_zone (Resource)

A domain hosted on the platform's nameservers. Point the domain's NS records at them at your registrar for its records (masterdaweb_dns_record) to answer. Destroying it removes every record in it.

Point the domain at `name_servers` at its registrar for the zone's records to answer. Destroying a zone removes
every record in it.

## Example Usage

```terraform
resource "masterdaweb_dns_zone" "example" {
  name = "example.com"
}

# The NS records to set at the registrar.
output "name_servers" {
  value = masterdaweb_dns_zone.example.name_servers
}
```

## Schema

### Required

- `name` (String) The root domain, like example.com (no scheme, no trailing dot). Changing it replaces the zone.

### Read-Only

- `created_at` (String) When the zone was created (RFC 3339).
- `id` (String) The zone's id.
- `name_servers` (List of String) The platform's nameservers: the NS records to set for the domain at its registrar.

## Import

A zone is imported by its id or by the domain:

```shell
# By id or by the domain.
terraform import masterdaweb_dns_zone.example 0193f0e2-8c1d-7a7e-9b1e-2f6a4c0d9e11
terraform import masterdaweb_dns_zone.example example.com
```
