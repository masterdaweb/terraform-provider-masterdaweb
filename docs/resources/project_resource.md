# masterdaweb_project_resource (Resource)

An instance, a database or a bucket in a project (masterdaweb_project). A resource is in one project at most: putting it in one moves it from the other. Destroying this takes the resource out of the project; the resource itself is not touched.

A resource is in one project at most: putting it in one moves it out of the other. Destroying this takes the
resource out of the project; the resource itself is not touched. Manage an instance's project here or with its
`project_id`, not both.

## Example Usage

```terraform
resource "masterdaweb_project_resource" "web" {
  project_id  = masterdaweb_project.shop.id
  kind        = "INSTANCE"
  resource_id = masterdaweb_instance.web.id
}

resource "masterdaweb_project_resource" "files" {
  project_id  = masterdaweb_project.shop.id
  kind        = "BUCKET"
  resource_id = masterdaweb_object_storage_bucket.files.name
}
```
