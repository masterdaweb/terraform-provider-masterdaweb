# masterdaweb_serverless_domain (Resource)

A domain of yours on a web service. Create the DNS records in dns_records at your DNS provider: the domain is checked every few minutes and its certificate issued once they are found.

A subdomain (`app.example.com`) takes a TXT record that proves it is yours and a CNAME. A root domain
(`example.com`) cannot have a CNAME: create the TXT record and either the ALIAS (if your DNS host offers
ALIAS or CNAME flattening) or the A records, which send visitors to `www`. Web services take up to 3
domains; their own address (`url`) comes with them.

Terraform does not wait for the domain to become active: `status` and `dns_records[*].found` say where the
last check stood.

## Example Usage

```terraform
resource "masterdaweb_serverless_domain" "site" {
  service_id = masterdaweb_serverless_service.web.id
  hostname   = "shop.example.com"
}

# The records to create at your DNS provider.
output "dns_records" {
  value = masterdaweb_serverless_domain.site.dns_records
}
```

## Schema

### Required

- `hostname` (String) The hostname, like app.example.com, or a root domain like example.com. Changing it replaces the domain.
- `service_id` (String) The web service the domain points to. Changing it replaces the domain.

### Read-Only

- `activated_at` (String) When the domain became active (RFC 3339).
- `apex` (Boolean) Whether it is a root domain (no CNAME possible: an ALIAS, or A records to the redirect service).
- `created_at` (String) When the domain was added (RFC 3339).
- `dns_records` (Attributes List) The DNS records to create. A root domain has alternatives, told apart by option: alias (if your DNS has ALIAS or flattening) or redirect (A records that send visitors to www). (see [below for nested schema](#nestedatt--dns_records))
- `error` (String) Why the domain is not active yet, when the last check said.
- `id` (String) The domain's id.
- `redirect_to` (String) A root domain pointed at the redirect service sends its visitors here.
- `status` (String) PENDING_DNS (waiting for the records), PENDING_CERTIFICATE, ACTIVE or FAILED, when last read.

### Nested Schema for `dns_records`

Read-Only:

- `found` (Boolean) Whether the last check found it.
- `name` (String) The record's name.
- `option` (String) Root domains: alias or redirect.
- `type` (String) TXT, CNAME, ALIAS or A.
- `value` (String) The record's value.

## Import

A domain is imported by its id, or as `<service_id>/<hostname>`:

```shell
# By id, or as <service_id>/<hostname>.
terraform import masterdaweb_serverless_domain.site 0193f0e2-aa11-7b22-8c33-4d44e55f6677
terraform import masterdaweb_serverless_domain.site 0193f0e2-9a4b-7c2d-8e1f-3a5b6c7d8e9f/shop.example.com
```
