# masterdaweb_dns_record (Resource)

A record set: every value at one name and type in a zone (two A records for www are one masterdaweb_dns_record with two records). Terraform owns the whole set.

One resource is a whole record set: every value at one name and type (two A records for `www` are one
`masterdaweb_dns_record` with two `records`), changed in one step. Creating a record set that already exists is
refused: import it to manage it. Values are compared as the nameservers keep them, so `www.example.com` and
`www.example.com.`, or a TXT with or without its quotes, are the same.

## Example Usage

```terraform
resource "masterdaweb_dns_record" "www" {
  zone_id = masterdaweb_dns_zone.example.id
  name    = "www"
  type    = "A"
  ttl     = 300
  records = ["203.0.113.10", "203.0.113.11"]
}

resource "masterdaweb_dns_record" "blog" {
  zone_id = masterdaweb_dns_zone.example.id
  name    = "blog"
  type    = "CNAME"
  records = ["www.example.com"]
}

resource "masterdaweb_dns_record" "mx" {
  zone_id = masterdaweb_dns_zone.example.id
  name    = "@"
  type    = "MX"
  records = ["10 mail.example.com", "20 mail2.example.com"]
}

resource "masterdaweb_dns_record" "spf" {
  zone_id = masterdaweb_dns_zone.example.id
  name    = "@"
  type    = "TXT"
  records = ["v=spf1 mx -all"]
}
```

## Schema

### Required

- `name` (String) The name relative to the zone (www), @ for the zone itself, or a fully qualified name in the zone. Changing it replaces the record set.
- `records` (Set of String) The values: an address for A/AAAA, a hostname for CNAME/NS, "<priority> <host>" for MX, "<priority> <weight> <port> <target>" for SRV, the text for TXT (quotes optional). A CNAME has one.
- `type` (String) A, AAAA, CNAME, MX, TXT, NS, SRV or CAA. Changing it replaces the record set.
- `zone_id` (String) The zone (masterdaweb_dns_zone). Changing it replaces the record set.

### Optional

- `ttl` (Number) Seconds resolvers may keep the answer: 60 to 604800.

### Read-Only

- `fqdn` (String) The fully qualified name, as the nameservers answer it (with its trailing dot).
- `id` (String) <zone_id>/<name>/<type>.

## Import

A record set is imported as `<zone_id>/<name>/<type>`:

```shell
# <zone_id>/<name>/<type>, the name as in the configuration (www, @).
terraform import masterdaweb_dns_record.www 0193f0e2-8c1d-7a7e-9b1e-2f6a4c0d9e11/www/A
```
