# masterdaweb_object_storage_key (Resource)

An S3 access key to the account's buckets, for tools outside the platform (a service gets its own through a binding). Its secret is shown once, when it is made: Terraform keeps it in the state (sensitive). Every change makes a new key.

The secret is shown by the API once, when the key is made: Terraform keeps it in its state (which is
sensitive) and it is not imported. Every change makes a new key. Making and revoking keys is an
administrator's, and revoking takes `storage:delete`.

## Example Usage

```terraform
resource "masterdaweb_object_storage_key" "ci" {
  name    = "ci-uploads"
  access  = "read_write"
  buckets = [masterdaweb_object_storage_bucket.files.name]
}

output "ci_access_key_id" {
  value = masterdaweb_object_storage_key.ci.access_key_id
}

output "ci_secret_access_key" {
  value     = masterdaweb_object_storage_key.ci.secret_access_key
  sensitive = true
}
```

## Schema

### Required

- `name` (String) The key's name, up to 64 characters.

### Optional

- `access` (String) read_write or read_only.
- `buckets` (Set of String) The buckets it reaches, by name; every bucket of the account (present and future) when left out.
- `expires_at` (String) When the key stops working (RFC 3339); never when left out.

### Read-Only

- `access_key_id` (String) The access key id (the S3 user).
- `created_at` (String) When the key was made (RFC 3339).
- `id` (String) The key's id.
- `secret_access_key` (String, Sensitive) The secret, shown once by the API (not imported).

## Import

A key is imported by its id (without its secret):

```shell
# By id. The secret is not imported: the API shows it once, when the key is made.
terraform import masterdaweb_object_storage_key.ci 0193f0e2-8c1d-7a7e-9b1e-2f6a4c0d9e11
```
