# masterdaweb_ssh_key (Resource)

An SSH public key of the account, put on Linux instances for root when they are created (masterdaweb_instance.ssh_key_ids).

A key is copied onto an instance when the instance is built or reinstalled (`ssh_key_ids`): renaming or
destroying it here never changes a machine that already has it. An account keeps up to 100 keys, each once.

## Example Usage

```terraform
resource "masterdaweb_ssh_key" "laptop" {
  name       = "laptop"
  public_key = file("~/.ssh/id_ed25519.pub")
}
```

## Schema

### Required

- `name` (String) The key's name, up to 64 characters. Changed in place.
- `public_key` (String) The public key, one OpenSSH line (ssh-ed25519 AAAA… comment), like file("~/.ssh/id_ed25519.pub"): Ed25519, RSA of 2048 bits or more, ECDSA, or a security key's. An account keeps a key once. Changing it replaces the key.

### Read-Only

- `created_at` (String) When the key was added (RFC 3339).
- `fingerprint` (String) The key's SHA256 fingerprint, as ssh-keygen -lf shows it.
- `id` (String) The key's id.
- `type` (String) The key's type, like ssh-ed25519.

## Import

A key is imported by its id:
