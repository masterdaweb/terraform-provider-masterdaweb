# masterdaweb_object_storage_bucket (Resource)

An Object Storage bucket, read and written with any S3 tool through the endpoint `mw storage info` names, or bound to a service. Private and protected from deletion unless said otherwise. A deleted bucket can be restored for a few days, and keeps its name until then.

Read and write the files with an access key and any S3 tool (`mw storage info` gives the endpoint), or bind
the bucket to a service, which then gets a key of its own. A bucket is protected from deletion by default and
is not deleted while services are bound to it. A deleted bucket can be restored for a few days (`mw storage
restore`) and keeps its name until then.

## Example Usage

```terraform
resource "masterdaweb_object_storage_bucket" "files" {
  name = "shop-files-acme" # unique on the whole platform

  quota_bytes = 50000000000 # 50 GB
  quota_mode  = "alert"

  cors = [{
    allowed_origins = ["https://shop.example.com"]
    allowed_methods = ["GET", "PUT"]
    allowed_headers = ["content-type"]
    max_age_seconds = 3600
  }]

  lifecycle_rules = [{
    id          = "tmp"
    prefix      = "tmp/"
    expire_days = 7
  }]
}

resource "masterdaweb_object_storage_bucket" "images" {
  name   = "shop-images-acme"
  public = true
}
```

## Schema

### Required

- `name` (String) The bucket's name: 3 to 63 lowercase letters, digits and single hyphens, unique on the whole platform. Changing it replaces the bucket.

### Optional

- `abort_multipart_days` (Number) Unfinished uploads are discarded after this many days (7 by default). 0: never.
- `cors` (Attributes List) CORS rules, for browsers that read or upload files from another site. (see [below for nested schema](#nestedatt--cors))
- `deletion_protection` (Boolean) Whether the bucket is protected from deletion. On by default: to destroy it, set it to false and apply first.
- `lifecycle_rules` (Attributes List) Rules that delete files some days after they were written. (see [below for nested schema](#nestedatt--lifecycle_rules))
- `public` (Boolean) Whether anyone may read its files (never write them), at public_url. Making an existing bucket public takes a token with storage:delete, of an administrator.
- `quota_bytes` (Number) A size limit in bytes, from 1 MB (1000000) up. None when left out.
- `quota_mode` (String) What reaching the size limit does: alert (an e-mail, the default) or block (uploads refused).

### Read-Only

- `created_at` (String) When the bucket was created (RFC 3339).
- `id` (String) The bucket's id.
- `location` (String) Where the bucket keeps its data.
- `public_url` (String) Where a public bucket serves its files.

### Nested Schema for `cors`

Required:

- `allowed_methods` (List of String) GET, PUT, POST, DELETE or HEAD.
- `allowed_origins` (List of String) Sites allowed, like https://shop.example.com (one * wildcard at most).

Optional:

- `allowed_headers` (List of String) Request headers allowed, like content-type.
- `expose_headers` (List of String) Response headers the browser may read, like ETag.
- `max_age_seconds` (Number) How long a browser may keep the answer to its preflight request, up to a week.


<a id="nestedatt--lifecycle_rules"></a>
### Nested Schema for `lifecycle_rules`

Required:

- `expire_days` (Number) Days after which a file is deleted, from 1 to 36500.
- `id` (String) The rule's name: up to 64 letters, digits, dots, dashes or underscores, unique in the bucket.

Optional:

- `enabled` (Boolean) Whether the rule applies.
- `prefix` (String) Files whose names start with it, like tmp/. Empty: every file (an expiry of the whole bucket takes a token with storage:delete, of an administrator).

## Import

A bucket is imported by its name (or its id):

```shell
# By name (or id).
terraform import masterdaweb_object_storage_bucket.files shop-files-acme
```
