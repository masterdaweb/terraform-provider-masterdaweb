# masterdaweb_database (Resource)

A managed PostgreSQL, MySQL, MariaDB or Redis (Valkey) database, billed by the hour. It is ready a few minutes after it is created (status running); Terraform does not wait, and a bound service's deployment waits for it. Protected from deletion unless deletion_protection is false.

Services reach a database through a [binding](serverless_binding), each with a login of its own; other
sources need `allowed_cidrs`. TLS is required.

- `size` changes resize the database once it runs, with a short restart; a bigger size comes with its
  bigger disk. `disk_gb` grows the disk (never shrinks it).
- `extensions` are only ever added: an extension's objects are your data, so removing one is done on the
  database itself (`DROP EXTENSION`).
- `password` is the owner's, from when the database was created. It is not imported (an administrator
  reveals it in the console, or with `mw db password`).
- A database is protected from deletion by default, and is not deleted while services are bound to it.
  Its backups are kept for a few days after.

## Example Usage

```terraform
resource "masterdaweb_database" "db" {
  name       = "shop-db"
  engine     = "postgres"
  version    = "18"
  size       = "pg-1-1"
  project_id = masterdaweb_project.shop.id
  extensions = ["vector", "pg_trgm"]

  # Your own address, besides the services bound to it.
  allowed_cidrs = ["203.0.113.7"]

  maintenance_day      = "sunday"
  maintenance_hour_utc = 4

  # On by default. To destroy the database, set it to false and apply first.
  deletion_protection = true
}

resource "masterdaweb_database" "cache" {
  name            = "shop-cache"
  engine          = "valkey"
  size            = "kv-1-1"
  eviction_policy = "allkeys-lru"
}
```

## Schema

### Required

- `engine` (String) postgres, mysql, mariadb or valkey (Redis). Changing it replaces the database.
- `name` (String) The database's name: 3 to 63 lowercase letters, digits and single hyphens, starting with a letter, unique in the account. Changing it replaces the database.
- `size` (String) The size, like pg-1-1, my-1-1 or kv-1-1 (`mw db sizes` lists them). Changing it resizes the database with a short restart, once it is running.

### Optional

- `allowed_cidrs` (Set of String) Addresses or networks allowed to connect besides your services, like 203.0.113.7 or 198.51.100.0/24.
- `backups` (Boolean) PostgreSQL, MySQL, MariaDB: continuous backups, for restoring to any point in time. On by default.
- `deletion_protection` (Boolean) Whether the database is protected from deletion. On by default: to destroy it, set it to false and apply first.
- `disk_autogrow_max_gb` (Number) Grow the disk by itself past 85% used, up to this many GB. 0: off.
- `disk_gb` (Number) The disk, in GB. It starts at the size's own and only grows: set it once the database runs to grow it (up to 1000).
- `eviction_policy` (String) Redis: what happens when memory is full. noeviction (the default, for queues) or an LRU/LFU policy like allkeys-lru (for a cache).
- `extensions` (Set of String) PostgreSQL: the extensions to enable, like vector or pg_trgm. They are only ever added: removing one is done on the database itself (DROP EXTENSION).
- `maintenance_day` (String) The day of the weekly maintenance window (sunday … saturday), or daily.
- `maintenance_hour_utc` (Number) The hour of the maintenance window, UTC (0 to 23).
- `project_id` (String) The serverless project it belongs to (where the console shows it).
- `version` (String) The release series, like "18" (PostgreSQL), "8.4" (MySQL) or "11.8" (MariaDB). The newest on offer when left out. Changing it replaces the database.

### Read-Only

- `created_at` (String) When the database was created (RFC 3339).
- `database_name` (String) The database (schema) to connect to; none for Redis.
- `direct_uri` (String) PostgreSQL: the direct address, for migrations, without the password.
- `host` (String) Where the database answers.
- `id` (String) The database's id.
- `password` (String, Sensitive) The owner's password, as the API gave it when the database was created. Null after an import, or for a developer's token. Services get logins of their own through bindings.
- `pooler_port` (Number) PostgreSQL: the pooler's port (use it from apps).
- `port` (Number) PostgreSQL: the direct port; MySQL, MariaDB, Redis: their port.
- `status` (String) provisioning, running, updating, failed, hibernating or hibernated, when last read.
- `uri` (String) The address to connect to, without the password.
- `username` (String) The owner's user name.

## Import

A database is imported by its name (or its id):

```shell
# By name (or id). The owner's password is not imported.
terraform import masterdaweb_database.db shop-db
```
