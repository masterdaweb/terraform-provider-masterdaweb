# masterdaweb_vpn_gateway_settings (Resource)

The settings of an existing VPN gateway — the instance ordered from the VPN gateway image —, applied to it: Terraform saves them and applies them in place, waiting for the gateway. Whenever the gateway has changes waiting to be applied (made in the console, or a login whose apply did not go through), the next apply applies them too. A setting left out is the gateway's own. Destroying this resource stops managing the settings; the gateway keeps them.

The gateway itself is an instance, ordered from the VPN gateway image like any other
([`masterdaweb_instance`](instance)); this resource manages what runs on it. A setting the configuration leaves
out is the gateway's own and is not touched.

## Applying

Terraform saves the settings and applies them to the gateway in place, waiting for it (`timeouts`). Some
changes — `route_all_traffic`, or any change on a gateway of the previous generation — need a **rebuild**: the
machine is reinstalled with everything it had, a few minutes offline, everyone connected disconnected. Without
`allow_rebuild = true` such an apply fails, saying so, and the settings stay saved; with it, Terraform rebuilds
the gateway and waits.

`pending_changes` follows the gateway: whenever it has changes waiting — made in the console, or a
[`masterdaweb_vpn_user`](vpn_user) change whose apply did not go through — the next plan shows an update and
the apply applies them. Destroying the resource leaves the gateway as it is.

## Example Usage

```terraform
# The gateway is an instance ordered from the VPN gateway image.
data "masterdaweb_vpn_gateway" "office" {
  name = "office-vpn"
}

resource "masterdaweb_vpn_gateway_settings" "office" {
  gateway_id         = data.masterdaweb_vpn_gateway.office.id
  protocol           = "tcp"          # for networks that block UDP
  remote_access_pool = "10.66.0.0/24" # what people connecting get
  route_all_traffic  = true           # everything through the office
  mtu                = 1380

  # route_all_traffic needs a rebuild: a few minutes offline.
  allow_rebuild = true
}
```

## Schema

### Required

- `gateway_id` (String) The VPN gateway (masterdaweb_vpn_gateway). Changing it manages another gateway.

### Optional

- `allow_rebuild` (Boolean) Whether an apply that needs a rebuild — a few minutes offline, everyone disconnected — may rebuild the gateway. Left false, such an apply fails, saying so, and the changes stay saved.
- `allow_shared_logins` (Boolean) Whether one login may be connected from several devices at once.
- `mtu` (Number) The tunnel's MTU, 576 to 1500 (1420 by default, for networks behind carrier-grade NAT).
- `name` (String) The gateway's name: its instance's, renamed at once (no apply).
- `protocol` (String) The VPN app's transport: udp, or tcp for networks that block UDP.
- `remote_access_pool` (String) The addresses people connecting get, an IPv4 network like 10.8.0.0/24 that overlaps neither the gateway's private network nor a connected site. Changing it renumbers connected people; the profiles they hold keep working.
- `route_all_traffic` (Boolean) Whether all of a connected person's traffic goes through the gateway, not only the private network's. Changing it needs a rebuild (allow_rebuild).
- `timeouts` (Attributes) How long Terraform waits, per operation, as a duration like "30m" or "1h". (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `apply_mode` (String) What the next apply does: in_place, or rebuild.
- `id` (String) The gateway's id.
- `instance_id` (String) The instance the gateway runs on.
- `pending_changes` (Boolean) Whether the gateway has changes waiting to be applied. When it has, the next plan applies them.
- `public_ip` (String) The address people and sites connect to.
- `wireguard_listen_port` (Number) The UDP port WireGuard site connections reach.
- `wireguard_public_key` (String) The gateway's WireGuard public key, for the far end of a WireGuard site connection.

## Import

The settings are imported by the gateway's id:

```shell
# By the gateway's id.
terraform import masterdaweb_vpn_gateway_settings.office 0193f0e2-8c1d-7a7e-9b1e-2f6a4c0d9e11
```
