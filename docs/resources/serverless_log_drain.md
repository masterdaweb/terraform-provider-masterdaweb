# masterdaweb_serverless_log_drain (Resource)

Sends a project's logs to an HTTPS endpoint of yours, Datadog or Better Stack, near real time (about 30 seconds behind): every service's output from when it is made. A project takes up to 3. Making or changing one takes an administrator's token.

The API keeps the token encrypted and shows the address only shortened (`destination`): Terraform keeps the
configured `token` and `url`, and changing either replaces the log drain (the new one sends from when it is
made). A destination that keeps failing is turned off after 50 sends in a row (`status = "stopped"`); the
next apply with `enabled = true` turns it back on, resuming where it stopped.

## Example Usage

```terraform
resource "masterdaweb_serverless_log_drain" "datadog" {
  project_id = masterdaweb_project.shop.id
  kind       = "DATADOG"
  token      = var.datadog_api_key
  site       = "eu1"
}

resource "masterdaweb_serverless_log_drain" "betterstack" {
  project_id = masterdaweb_project.shop.id
  kind       = "BETTERSTACK"
  token      = var.betterstack_source_token
}

# Your own endpoint takes NDJSON lines: timestamp, message, project, service,
# revision, instance.
resource "masterdaweb_serverless_log_drain" "loki" {
  project_id = masterdaweb_project.shop.id
  kind       = "HTTPS"
  url        = "https://logs.example.com/ingest"
  token      = "Bearer ${var.ingest_token}"
}
```

## Schema

### Required

- `kind` (String) HTTPS (your endpoint takes NDJSON lines: timestamp, message, project, service, revision, instance), DATADOG or BETTERSTACK.
- `project_id` (String) The project whose logs are sent.

### Optional

- `enabled` (Boolean) Whether logs are sent. Turned back on, it resumes from where it stopped (within the 6 days the logs are kept).
- `site` (String) DATADOG: the account's site, us1 (the default), us3, us5, eu1, ap1 or ap2.
- `token` (String, Sensitive) DATADOG: the API key. BETTERSTACK: the source token. HTTPS: the Authorization header to send, like "Bearer …" (optional). Kept encrypted and never shown again; changing it replaces the log drain.
- `url` (String) HTTPS: the endpoint's https:// address. BETTERSTACK: the source's ingesting host (default in.logs.betterstack.com). Not used for Datadog. The API shows it shortened afterwards (destination); changing it replaces the log drain.

### Read-Only

- `created_at` (String) When the log drain was made (RFC 3339).
- `destination` (String) Where the logs go, as the API shows it: the host and the last characters of the address.
- `id` (String) The log drain's id.
- `last_error` (String) What the destination last answered, when it failed.
- `status` (String) ok (sending), failing (retrying after errors), stopped (turned off after too many failed sends in a row: set enabled to resume) or off, when last read.

## Import

A log drain is imported by its id, or as `<project_id>/<id>`. Its token, and an HTTPS address, cannot be
read back: Terraform takes the ones in the configuration (an address that does not look like the drain's
own is refused).

```shell
# By id, or as <project_id>/<log drain id>. The token (and an HTTPS address)
# cannot be read back: Terraform takes the configured ones.
terraform import masterdaweb_serverless_log_drain.datadog 0193f0e2-8c1d-7a7e-9b1e-2f6a4c0d9e11/0193f0e2-bb22-7c33-8d44-5e55f66a7788
```
