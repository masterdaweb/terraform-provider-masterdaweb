# masterdaweb_webhook (Resource)

A webhook: the account's events (deployments, alerts, databases, billing) sent to an address of yours as signed JSON, or as a message to a Slack or Discord channel.

A `GENERIC` webhook's deliveries are signed: `MW-Signature: t=<unix time>,v1=<hex>`, the HMAC-SHA256 of
`<t>.<body>` with `secret`. The secret is shown by the API once, when the webhook is added: Terraform keeps it in
its state (which is sensitive). Adding, changing and removing webhooks is an administrator's (`webhooks:write`,
and `webhooks:delete` to remove one).

## Example Usage

```terraform
# Your endpoint gets signed JSON: check MW-Signature with the secret.
resource "masterdaweb_webhook" "ops" {
  url         = "https://ops.example.com/hooks/masterdaweb"
  description = "Deploys and alerts"
  events      = ["deployment.failed", "alert.*"]
}

output "webhook_secret" {
  value     = masterdaweb_webhook.ops.secret
  sensitive = true
}

# A Slack channel gets a message per event.
resource "masterdaweb_webhook" "billing" {
  kind   = "SLACK"
  url    = var.slack_webhook_url
  events = ["billing.*"]
  locale = "pt-BR"
}

variable "slack_webhook_url" {
  type      = string
  sensitive = true
}
```

## Schema

### Required

- `url` (String, Sensitive) Where events go, an https:// address. It is a credential: the API never shows it again (masked_url). Changing it replaces the webhook.

### Optional

- `description` (String) What it is for, up to 255 characters. Changed in place.
- `enabled` (Boolean) Whether it gets events. The platform switches off a webhook that keeps failing (disabled_reason): the next apply switches it on again.
- `events` (Set of String) The events it gets, like deployment.failed, or a family like alert.*; every event when left out. Changed in place.
- `kind` (String) GENERIC (your https:// address gets JSON signed with MW-Signature), SLACK or DISCORD (an incoming webhook's address). Changing it replaces the webhook.
- `locale` (String) The language of a Slack or Discord message, like pt-BR or en. Changing it replaces the webhook.

### Read-Only

- `created_at` (String) When it was added (RFC 3339).
- `disabled_reason` (String) Why the platform switched it off: failing or removed.
- `id` (String) The webhook's id.
- `masked_url` (String) The address as the API shows it: its host and last characters.
- `secret` (String, Sensitive) GENERIC: the secret that signs deliveries (MW-Signature: t=…,v1=…, an HMAC-SHA256 of <t>.<body>), shown once by the API (not imported).

## Import

A webhook is imported by its id:

```shell
# By id. The address and the secret are not imported: the configuration's
# address is taken as it is.
terraform import masterdaweb_webhook.ops 0193f0e2-8c1d-7a7e-9b1e-2f6a4c0d9e11
```
