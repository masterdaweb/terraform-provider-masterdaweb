# masterdaweb_vpc_attachment (Resource)

An instance on a VPC of its region. Attaching plugs a private NIC into the instance (Terraform waits until the VPC lists it); an instance is on one VPC at a time. Destroying it takes the private NIC out and keeps the public one.

Attaching plugs a private network interface into the instance — Terraform waits for the operation that does it — at
`private_ip` (inside the VPC's subnet, and free) or at an address DHCP picks. The interface comes up at the
instance's next restart, or at once with `restart = true`. An instance is on one VPC at a time, of its own region.

## Example Usage

```terraform
resource "masterdaweb_vpc_attachment" "web" {
  vpc_id      = masterdaweb_vpc.backend.id
  instance_id = masterdaweb_instance.web.id
  private_ip  = "10.20.0.10" # DHCP picks one when left out

  # Restart it so the private interface comes up now.
  restart = true
}
```

## Schema

### Required

- `instance_id` (String) The instance. Changing it replaces the attachment.
- `vpc_id` (String) The VPC. Changing it moves the instance (replaces the attachment).

### Optional

- `private_ip` (String) The instance's address on the VPC, inside its subnet and free; DHCP picks one when left out. Changing it makes a new attachment.
- `restart` (Boolean) Whether the instance restarts when it joins or leaves, so the change to its private NIC applies at once; otherwise it applies at its next restart.
- `timeouts` (Attributes) How long Terraform waits, per operation, as a duration like "30m" or "1h". (see [below for nested schema](#nestedatt--timeouts))

### Read-Only

- `id` (String) <vpc_id>/<instance_id>.
