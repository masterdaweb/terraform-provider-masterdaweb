# masterdaweb_project (Resource)

A project: what groups instances, databases, buckets and serverless services under one name. Instances, databases and buckets join it with masterdaweb_project_resource (or project_id on an instance or a database); services are made in it.

Instances, databases and buckets join a project with `masterdaweb_project_resource`; serverless services are
made in it (`project_id` of `masterdaweb_serverless_service`).

A project is protected from deletion by default. Destroying it while `deletion_protection` is true fails
with a message saying so: set it to false, run `terraform apply`, then destroy. Destroying a project tears down
its serverless services; the instances, databases and buckets in it are not touched — they only leave it.
Terraform waits until it is gone, so its name is free again.

## Example Usage

```terraform
resource "masterdaweb_project" "shop" {
  name        = "shop"
  description = "The shop's site, API and workers"

  # On by default. To destroy the project, set it to false and apply first.
  deletion_protection = true
}
```

## Schema

### Required

- `name` (String) The project's name: 1 to 64 characters, unique in the account. It can be changed.

### Optional

- `deletion_protection` (Boolean) Whether the project is protected from deletion. On by default: to destroy the project, set it to false and apply first.
- `description` (String) What the project is for, up to 500 characters.

### Read-Only

- `created_at` (String) When the project was created (RFC 3339).
- `id` (String) The project's id.
- `region` (String) Where the project's serverless services run.
