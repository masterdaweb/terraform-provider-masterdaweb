# masterdaweb_reverse_dns (Resource)

The reverse DNS (PTR) of one of the account's addresses. The hostname must resolve to the address first (forward-confirmed): create its A/AAAA record before. Destroying it puts the default back.

The hostname must resolve to the address first (forward-confirmed reverse DNS, which mail servers check
anyway): create its A or AAAA record before, and make the reverse DNS depend on it. A new address may have to
be held a few days before its reverse DNS can change. Destroying the resource puts the default name back.

## Example Usage

```terraform
resource "masterdaweb_dns_record" "mail" {
  zone_id = masterdaweb_dns_zone.example.id
  name    = "mail"
  type    = "A"
  records = [masterdaweb_instance.mail.ipv4_address]
}

resource "masterdaweb_reverse_dns" "mail" {
  ip       = masterdaweb_instance.mail.ipv4_address
  hostname = "mail.example.com"

  # The name must resolve to the address first.
  depends_on = [masterdaweb_dns_record.mail]
}
```

## Schema

### Required

- `hostname` (String) The fully-qualified name the address answers with, like mail.example.com. It must resolve to the address. Changed in place.
- `ip` (String) The IPv4 or IPv6 address, one of the account's. Changing it replaces the resource.

### Read-Only

- `default_hostname` (String) The name it answers with by default.
- `id` (String) The address.
- `instance_id` (String) The instance the address is on.
- `version` (Number) 4 or 6.
