# masterdaweb_serverless_outbound_addresses (Data Source)

The addresses services reach the internet from, for allowlists at a bank, an ERP or a database elsewhere. Put the ranges on an allowlist: they are stable. The addresses in use now change when the platform replaces a server, always within the ranges.

## Example Usage

```terraform
data "masterdaweb_serverless_outbound_addresses" "current" {}

# Allow the services on a database elsewhere: the ranges are stable.
output "allowlist" {
  value = data.masterdaweb_serverless_outbound_addresses.current.ranges
}
```
