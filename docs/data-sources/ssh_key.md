# masterdaweb_ssh_key (Data Source)

Looks up an SSH key of the account by its id, its name or its fingerprint, for masterdaweb_instance.ssh_key_ids.

## Example Usage

```terraform
data "masterdaweb_ssh_key" "laptop" {
  name = "laptop"
}

resource "masterdaweb_instance" "web" {
  name        = "web-1"
  region_id   = "3"
  plan        = "c2m4"
  image       = "debian-12"
  ssh_key_ids = [data.masterdaweb_ssh_key.laptop.id]
}
```
