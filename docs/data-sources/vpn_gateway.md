# masterdaweb_vpn_gateway (Data Source)

Looks up a VPN gateway — an instance ordered from the VPN gateway image — by its id, its name or its instance: its address, settings, and whether changes wait to be applied.

## Example Usage

```terraform
data "masterdaweb_vpn_gateway" "office" {
  name = "office-vpn"
}

output "vpn_address" {
  value = data.masterdaweb_vpn_gateway.office.public_ip
}

output "wireguard_public_key" {
  value = data.masterdaweb_vpn_gateway.office.wireguard_public_key
}
```

## Schema

### Optional

- `id` (String) The gateway's id. Give the id, the name or the instance.
- `instance_id` (String) The instance it runs on (masterdaweb_instance ordered from the VPN gateway image). Give the id, the name or the instance.
- `name` (String) The gateway's name, which only it has. Give the id, the name or the instance.

### Read-Only

- `allow_shared_logins` (Boolean) Whether one login may be connected from several devices at once.
- `applied_at` (String) When it last applied its settings (RFC 3339).
- `apply_mode` (String) What its next apply does: in_place, or rebuild.
- `apply_operation_id` (String) The apply in flight, when there is one (an operation).
- `apply_state` (String) idle, queued, applying or failed.
- `created_at` (String) When it was made (RFC 3339).
- `included_site_connections` (Number) How many site connections its plan includes.
- `last_apply_error_code` (String) Why its last apply failed.
- `location` (String) Where it runs.
- `mtu` (Number) The tunnel's MTU.
- `pending_changes` (Boolean) Whether settings or logins changed since its last apply.
- `protocol` (String) The VPN app's transport: udp or tcp.
- `public_ip` (String) The address people and sites connect to.
- `remote_access_pool` (String) The addresses people connecting get (CIDR).
- `remote_access_pool_issue` (String) Why the pool needs changing, when it overlaps something.
- `route_all_traffic` (Boolean) Whether all of a connected person's traffic goes through it.
- `running` (Boolean) Whether its instance is powered on.
- `site_connections_count` (Number) How many sites are connected to it.
- `update_available` (Boolean) Whether a newer version of the gateway software is available.
- `users_count` (Number) How many logins it has.
- `wireguard_listen_port` (Number) The UDP port WireGuard site connections reach.
- `wireguard_public_key` (String) Its WireGuard public key, for the far end of a WireGuard site connection.
