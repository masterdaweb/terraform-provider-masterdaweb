# masterdaweb_images (Data Source)

The operating systems and ready-made apps an instance is installed with (the image of masterdaweb_instance), with what each needs. The filters narrow the list.

## Example Usage

```terraform
data "masterdaweb_images" "apps" {
  type = "MARKETPLACE_APP"
}

# What each app asks before it can run (masterdaweb_instance.app_inputs).
output "app_inputs" {
  value = { for i in data.masterdaweb_images.apps.images : i.code => [for q in i.inputs : q.key] }
}
```
