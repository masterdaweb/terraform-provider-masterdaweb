# masterdaweb_dns_zone (Data Source)

Looks up a DNS zone by its id or its name (the domain), for masterdaweb_dns_record.zone_id.

## Example Usage

```terraform
data "masterdaweb_dns_zone" "example" {
  name = "example.com"
}

resource "masterdaweb_dns_record" "www" {
  zone_id = data.masterdaweb_dns_zone.example.id
  name    = "www"
  type    = "A"
  records = ["203.0.113.10"]
}
```
