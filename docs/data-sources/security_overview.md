# masterdaweb_security_overview (Data Source)

The account's security score in the Security Center and what it is made of: open findings by severity, the engines behind the score, how much the scans reach, and the worst instances and resources.

Reading it takes `security:read`.

## Example Usage

```terraform
data "masterdaweb_security_overview" "account" {}

output "security_score" {
  value = data.masterdaweb_security_overview.account.score
}

# A pipeline step can fail on new critical findings.
output "open_critical" {
  value = data.masterdaweb_security_overview.account.open_findings.critical
}
```

### Read-Only

- `engines` (Attributes List) The parts the score is made of. (see [below for nested schema](#nestedatt--engines))

- `id` (String) Always security_overview.

- `open_findings` (Attributes) What still counts, by severity: neither resolved nor excepted. (see [below for nested schema](#nestedatt--open_findings))
- `resources` (Attributes List) Every other kind of resource: how many there are and how many the checks looked at. (see [below for nested schema](#nestedatt--resources))
- `scanning_available` (Boolean) False while the platform has scanning paused: the score is not being refreshed.
- `score` (Number) The account's score, 0–100; null before the first check.
- `worst_instances` (Attributes List) Up to five instances, worst first. (see [below for nested schema](#nestedatt--worst_instances))
- `worst_resources` (Attributes List) Up to five other resources, worst first. (see [below for nested schema](#nestedatt--worst_resources))
